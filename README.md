# 発注書 進捗管理ツール

発注書の作成・自動転記・荷受〜受渡の進捗管理を行う社内向けツールです。発注書を作成すると、内容が自動でGoogleスプレッドシートに転記されるため、手作業での二重入力が不要になります。

複数の担当者がそれぞれ発注書を発行していても、共用の荷受場に置いた端末で「一覧」の「到着待ち（荷受チェック）」「受渡待ち（受渡チェック）」タブを開けば、届いた荷物がどの発注書のもので誰宛か（担当者名・部署名・納品場所）をその場で確認し、「到着」「受渡」をワンクリックで記録できます。会社への荷受から担当者への受渡までをスムーズにすることが主な目的です。

見積書進捗管理ツールと対になる独立したツールで、データ・スプレッドシートは共有しません。

## 公開URL
https://onuma-spec.github.io/anken-kanri-hacchu/

## 構成
- `index.html` — ツール本体（単一HTMLファイル）
- `gas_template.gs` — 集計先となるGoogle Apps Scriptのテンプレート（`index.html`内の「①発注書データの保存先を用意する」からもコピーできます）
- `sync_gas_code.js` — `gas_template.gs`の内容を`index.html`内の埋め込みコードへ同期するスクリプト（開発用。利用者が実行する必要はありません）

## 仕組み
1. `index.html`をブラウザで開き、発注書を作成するフォームに入力して送信
2. 内容が自動で各社自身のGoogleスプレッドシート（発注ヘッダー・発注明細タブ）に転記される。書類番号もこの時点で自動採番される
3. 送信直後に印刷用の発注書レイアウトが表示され、そのまま印刷・PDF保存できる
4. 荷物が届いたら、荷受場の端末等で`index.html`の「一覧」→「📦 到着待ち（荷受チェック）」タブを開き、該当の品目を検索して「到着を記録」ボタンを押す
5. 担当者に引き渡したら、「🤝 受渡待ち（受渡チェック）」タブから該当の品目を検索して「受渡を記録」ボタンを押す（4・5とも、ワンクリックで完了しスプレッドシートを直接編集する必要はない）
6. 「⚠️ 納期遅延一覧」から、納期超過などの案件をいつでも確認できる

`index.html`はフロントエンドのみで、データは一切保持しません。バックエンド（GAS＋スプレッドシート）は利用する各社が自分のGoogleアカウント内に個別に構築するため、データは各社のGoogle上に閉じます。

## 初期セットアップ
`index.html`をブラウザで開くと表示される「①発注書データの保存先を用意する」「②接続を確認する」の手順に沿って進めてください。GASコードのコピー・貼り付け・デプロイまで、画面内の案内だけで完結します。

セットアップ後、スプレッドシートに自動生成される「設定」タブに自社名など（自社名のみ必須）を、「登録リスト」タブに部署名候補・担当者一覧を入力しておくと、発注書作成フォームで選択できるようになります。「設定」タブの「受渡待ち滞留日数のしきい値」（初期値1日）は、着荷後この日数以上受渡されていない品目を「受渡待ち（受渡チェック）」タブで強調表示する基準日数です。

## 主な機能
- 発注書作成・自動転記・自動採番（`prefix-yyyymm-連番`）
- 印刷／PDF保存用レイアウト、過去の発注書を複製しての新規作成
- **二重発注防止**：発注書を印刷するたびにスプレッドシート側へ確認し、初回は記録するだけ、2回目以降は「既に印刷済みです」と警告した上で続行可否を選べる
- **荷受チェック／受渡チェック**：「一覧」から「到着」「受渡」をそれぞれ専用タブでワンクリック記録。品目ごとの状態は「到着待ち／受渡待ち／受渡済み」の3段階で管理され、担当者名・部署名・納品場所が一覧で確認できる
- **異常の強調表示**：到着待ちタブで納期を超過している品目、受渡待ちタブで着荷からしきい値以上経過している品目は、行全体の色分け＋⚠️バッジで強調表示（バナーでも件数を通知）
- **取り消し**：記録の直後に画面下へ「元に戻す」通知が表示され、タップまたは次の記録操作まで残る。直前の1件だけをその場で取り消せる（それより前の記録を修正したい場合は、スプレッドシートの「発注明細」タブを直接編集する）
- 納期遅延一覧：納期超過の品目を担当者ごとに絞り込んで確認できる
- 一覧（到着待ち、受渡待ち、納期遅延一覧、全品目一覧の4タブ）

見積書ツールにある「差分表示」（バックアップ・比較・復元機能）は発注書側には実装していません。

## データについて
すべてのデータ（発注書の内容・進捗など）は、利用者自身が作成したGoogleスプレッドシートに保存されます。本ツール（`index.html`）や開発者側には一切のデータが送信・保存されません。

## 注意事項
GAS Webアプリは認証なし（アクセスできるユーザー：全員）で公開されるため、ウェブアプリURLを知っていれば技術的知識のある第三者がデータを閲覧・変更できる可能性があります。社内の信頼できるメンバーの範囲でURLを共有してください。
